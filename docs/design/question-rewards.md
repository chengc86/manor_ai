# Question rewards

Quick questions earn 10 coins, standard questions 20, challenge questions 30, and extended questions 40. The initial bank uses prompt and passage rules; individual questions can override rewardGroup for editorial tuning. New content should explicitly select a group based on difficulty and expected effort.

Rewards are displayed before answering and snapshotted on the server when issued. Incorrect answers earn nothing. Existing pending questions retain their old 20-coin reward. Corrected mistakes retain the existing 24-hour retry policy and cannot earn repeatedly after success. Existing balances are unchanged. Elapsed browser time does not affect rewards.
