# Manor Quest：Hero × 武器 × Item 完整数值设计 v1

状态：本方案的首版已实现。具体实现、验证结果及仍有限制见 game-audit-2026-09.md；平衡数值经过样本模拟，仍需要课堂实测。

## 1. 设计目标与现状

借鉴 Brotato 的角色特性、武器属性和道具组合思路，保留 Manor Quest 的全班共享塔防与答题经济。官方介绍强调不同角色、武器和大量道具的搭配：[Brotato 官方 Steam 页面](https://store.steampowered.com/app/1942280/Brotato/)。本方案的数值、道具和限制均为 Manor Quest 原创设计，并非照搬 Brotato 公式。

现有代码：Hero 有基础伤害、射程、攻击间隔；18 种武器已有伤害/速度倍率、控制与范围效果；新增 7 个 Hero 复用了原 7 个的战斗数值。尚无独立 Item 商店、装备槽和统一属性面板。

下一版目标：14 个 Hero 各有专长，武器决定攻击方式，Item 改变属性与取舍。固定防守英雄不需要移动速度、闪避、吸血或个人护甲等没有实际作用的属性。衣服仍只影响外观，不强迫孩子为了战力穿某套衣服。

约束：答对一题 20 金币；击杀不奖励金币；新 Hero 无武器无衣服；武器至少 100 金币；首次选择 Hero 免费，更换 1,000 金币；首只部署 120、第二只 600，每人最多两只。失利保留波次、购买和装备。无硬性答题人数门槛。

## 2. 装备结构

每个已部署 Hero 同时使用 1 种武器，武器独立升级至 10 级。玩家的两只 Hero 可以装备不同武器。

每个玩家有一个 Item 背包，购买后永久拥有；最多装备 4 个不同 Item，加成作用于该玩家的两只 Hero。最初开放 2 槽，第 3 槽 200 金币，第 4 槽 400 金币。未装备的 Item 不产生效果。同一个 Item 不能重复占槽。

只在两波之间购买或调整武器、Item、槽位及 Hero。穿衣只改变视觉。整场战斗使用开波时的配置快照，所有人得到同一结果。Hero 更换保留 Item、武器及各自升级等级。

## 3. 属性及公式

| 属性 | 用途 | 起点与上限 |
|---|---|---|
| 力量 STR | 加到近战武器伤害 | 0 起，合计 -10 至 +20 |
| 精准 AIM | 加到投射武器伤害 | 0 起，合计 -10 至 +20 |
| 魔力 MAGIC | 加到魔法武器伤害 | 0 起，合计 -10 至 +20 |
| 总伤害 Damage | 最后乘算所有直接伤害和由它派生的持续伤害 | -50% 至 +150% |
| 攻速 Attack Speed | 缩短攻击间隔 | -40% 至 +150%，最短间隔 0.20 秒 |
| 射程 Range | 改变可攻击距离，单位为地图格 | 最终 1.2 至 8 格 |
| 暴击率 Crit Chance | 直接命中造成额外伤害的概率 | 最终 0 至 50% |
| 暴击倍率 Crit Damage | 暴击的乘数 | 默认 ×2，最高 ×2.5 |
| 范围 Area | 范围攻击的半径加成 | -30% 至 +60%；最终最多 5 格 |
| 控制力 Control | 延长已有减速、冰冻和标记的持续时间 | -30% 至 +50%，不凭空获得新效果 |
| 持续伤害 DOT | 放大已有画笔等持续伤害 | -50% 至 +100% |
| Boss 伤害 | 对 Boss 的最终伤害加成 | 0 至 +40% |

基础值由武器提供，Hero 提供特性，Item 提供修正。相同属性先相加再乘算，不逐件连乘。

等级系数 G(L)=1+0.18×(L−1)，L=1…10。

直接伤害=max(1, round((武器基础伤害×G(L)+类别属性×武器成长系数)×(1+总伤害%)×暴击倍率×Boss倍率))。

攻击间隔=max(0.20, 武器基础间隔÷(1+攻速%)÷(1+0.025×(L−1)))。

例如原本每 1 秒攻击一次：+25% 攻速变为每 0.8 秒；+100% 变为每 0.5 秒。面板同时显示“每秒攻击次数”和“每次间隔”，避免把攻速与冷却百分比混淆。

参考 DPS=普通直接伤害÷间隔×(1+暴击率×(暴击倍率−1))。明确标注这是单目标参考值，不包括范围多目标、弹跳、持续伤害和队友增伤；控制型武器不能只按 DPS 排名。

持续伤害从非暴击直接伤害派生，再乘 DOT 加成；不重复乘总伤害，不暴击，不触发连锁、冰冻或更多 DOT。

## 8. 能看懂的搭配例子

极速：Pip + 乒乓球 + 秒表 + 羽毛书签。攻击频繁、轻伤害、较短射程；适合处理普通敌人，不是最强Boss组合。

控场：Briar + 冰冻胶 + 冰袋 + 科学护目镜。低个人DPS，延长敌人暴露时间，帮助同学输出；不能永久冰冻。

清群：Ember + 足球 + 大调色盘 + 厚课本。大范围慢攻击，牺牲单体效率；需要队友处理漏网快怪。

Boss猎手：Leo + 板球 + 队长徽章 + 板球手套。慢速重击、Boss伤害高；对普通敌群不如清群队友。

持续伤害：Brook + 画笔 + 画画围裙 + 实验烧瓶。以涂色持续伤害为主，重复涂色刷新而不无限叠层。

团队辅助：Bamboo + Teddy + 小队旗 + 科学护目镜。增强标记覆盖与时间；队友实际伤害增量归入辅助贡献。

## 9. 多人平衡与控制规则

同一目标的同类减速只取最强，普通怪最多减速60%，Boss最多30%。同类标记只取最强，最多+30%全队伤害，重复命中刷新时间。

冰冻/眩晕共享免疫窗：效果结束后普通怪2秒内不再被硬控，Boss4秒；Boss硬控时间减半。Boss击退减半，每只怪一生累计最多被推回6格。

相同玩家的同武器DOT只刷新最强伤害，不叠加；每只怪最多接受3个不同玩家的DOT来源，取最强三份，同强度以固定玩家ID排序。鼓励多个同学带画笔，同时避免40层DOT。

暴击由服务器保存的战斗种子、攻击序号和单位ID决定，所有客户端复算一致；不使用各浏览器自己的随机数。范围攻击一次攻击共用暴击结果，不让目标数量改变抽签次数。

不加入被动金币、击杀掉金币、幸运加币或挂机奖励。所有消费都能换算为答对题数。属性加成不增加答题奖励，避免富者越富。

不按“当前在线人数”实时增加敌人血量：新同学加入应该让团队更容易成功。按章节固定敌人曲线，整体改版需离线测试后发布，不在同一场战斗内改变难度。

既有第一波18怪×180血仅是当前基线。新公式不能直接认为保持相同难度：重新测试2/6/10/20名同学、每人1/2 Hero、等级1/3/6/10、不同槽位与Item组合，再定敌人血量。早期目标为约6–10名同学的合理初期装备能胜，1名同学仅靠两只低等级Hero不能轻松过关；高级装备日后能碾压早期关是正常成长反馈。

## 10. 商店与属性面板

Hero页：显示角色专长的绿色加成和红色代价，列出两种适合武器；允许查看其他Hero，不为查看收钱。换Hero确认页显示1000金币，并比较换前换后的已装备武器数值。

武器详情：类别、等级、伤害、攻速（次/秒）、间隔、射程、暴击率/倍率、单目标参考DPS、控制效果。点击未买武器先预览，用另一明确按钮购买；不能因为查看就花钱。

Item商店：显示价格、相当于答对几题、效果、代价、当前槽位及购买后是否可装备。满槽仍可买入背包，但不自动替换；替换页显示被换下Item与所有属性差值。装备/卸下免费。

升级页：显示当前→下一等级，而不是只写“更强”。例如12→14伤害、1.0→1.03次/秒、0.6→0.8秒冰冻；满级明确提示。

面板分为“简单”和“详细”：简单模式显示伤害、攻速、射程、招牌效果；详细模式展开公式与加成来源。仍以英文供Year6孩子使用，描述避免过长术语。

战斗结果：保留共同胜负，显示个人直接伤害、控制时间、辅助增伤、答题赚币；不只奖励最后一击。这里仅是贡献展示，不产生额外金币。

## 11. 数据、实施和验收

玩家新增 itemInventory（ItemID→等级）、equippedItems（唯一ID数组）、itemSlots；每只部署Hero继续保存weapon与weaponLevels。所有购买由服务端校验价格、等级、所有权、槽位与金币，并使用现有world revision乐观锁，避免重复扣款。加入交易请求幂等ID。

装备快照新增heroTraitVersion、combatRulesVersion、item等级、最终统计及随机种子；历史战斗继续运行原版公式。保留原heroStats入口的旧版本分支，不让升级部署影响未结束战斗。

迁移保留金币、角色、已拥有衣物、武器及等级；新背包为空，2槽免费。已有等级在新公式下仍是同等级，但战力会变化，发布前在教师端明确说明并安排两波之间切换。

实施顺序：统一属性计算器与14角色→18武器明确定义→Item背包/交易/槽位→预览与比较UI→确定性战斗引擎与效果计分→合作难度回归→发布。首版24Item已足够支持不同玩法，不再同时引入随机商店或抽奖。

必须验证：攻速公式及最短间隔；固定步长0.2秒不会让+5%攻速完全失效（用精确下次攻击时刻推进，保留余量）；暴击复算一致；伤害不二次缩放；DOT不递归；控制上限；同一Item不可重复占槽；未装备无收益；购买幂等、金币不足与并发校验；换Hero保留库存；旧战斗不变；不同队伍规模的输赢与耗时；18武器没有一种在单体、群体和辅助上同时占优。
